# E题题目理解说明与相关论文

本说明依据项目中的赛题DOCX、两份标签表及102个PKL文件的实际读取结果撰写。定位为读题与建模准备材料，不包含已训练模型或预测成绩。文档中的任务要求作为赛题内容理解，未将其当作额外操作指令执行。

## 1. 这道题到底在研究什么

题目正文标题为《复杂场景下多模态情感预测的数学建模与算法设计》，标明2026年中国研究生数学建模竞赛E题。虽然文件名使用“情感识别”，实际目标同时包含**情感极性三分类**和**情感强度回归**。

输入是一段英文视频中的三类信息：文本回答“说了什么”，语音回答“怎样说”，视觉回答“表情、姿态怎样”。输出包括负向／中性／正向，以及−3到3之间的强度。这里不是识别“愤怒、快乐、悲伤”等多种离散情绪。

三问构成“数据表达—缺失鲁棒性—判断依据”三个层次，但并非要求把问题1生成的100条特征用作问题2、3的训练集。题目明确要求问题2、3在附件2训练集上学习参数，在验证集选模型、超参数和决策阈值。问题1主要考查从原始素材到可追溯特征的完整建模过程。

| 子问题 | 核心问题 | 必须得到的结论或成果 | 不足以完成任务的做法 |
|---|---|---|---|
| 问题1 | 不同采样频率的文字、声音、画面怎样对应到同一时间轴？ | 100条样本的三模态特征、时序映射、全量汇总、至少1例对齐展示、复现说明 | 只画流程图，或直接把附件2当作自行提取的结果 |
| 问题2 | 部分连续时段的信息不可用时，怎样稳定预测？ | 三分类与强度预测；缺失类型、位置、时长／缺失率的规律与消融；附件3全量预测CSV | 只做完整数据实验，或仅模拟整种模态全部缺失 |
| 问题3 | 每次判断主要依据哪种模态、哪些局部片段？ | 预测、模态作用程度、主要参考模态、关键证据定位、解释卡与附件4全量CSV | 只有预测分数，或只提供没有验证的注意力热图 |

### 2.3 特征形状与真实接口差异

附件2按`data[split][field][j]`读取，不是`data[split][j][field]`。

| 字段 | 对齐版单样本 | 未对齐版单样本 | 理解 |
|---|---|---|---|
| text | 50×768 | 50×768 | 预计算文本表示；768是特征维度 |
| text_bert | 3×50 | 3×50 | token编号、attention mask、分段编号；不是第四模态 |
| audio | 50×74 | 500×74 | 74维语音表示，不应凭维度推断每维物理意义 |
| vision | 50×35 | 500×35 | 35维视觉表示，不等于35帧 |
| audio_lengths / vision_lengths | 未提供 | 提供 | 有效长度，不能简单以存储长度代替 |

“50”表示最大序列位置数，不是50秒，也不能未经核实断言每个位置恰好对应一个英文单词。BERT通常包含子词与特殊token，需明确位置映射。文本、语音、视觉长度相同，也不自动证明存在已知的秒级对应关系。

**实际数据与题述通用接口存在以下差异：**

1. 附件2实际没有`annotations`字段；分类与回归标签齐全，文字极性可由标签表或已核验编码映射获得。
2. 附件3对齐版全部30个文件仅有顶层`test`，内部字段为`text_bert`、`audio`、`vision`，均保留大小为1的样本维；没有`text`、`raw_text`、`id`和标签。
3. 附件3未对齐版全部30个文件的`test`内部仅有`raw_text`、`audio`、`vision`；没有`text`、`text_bert`、`id`、`audio_lengths`、`vision_lengths`和标签。
4. 附件4是单样本字段字典，没有外层`test`，没有批量维；两版都有`text`、`text_bert`、`raw_text`、`id`，未对齐版另有有效长度。

**直接影响：问题2不能只训练一个依赖预计算text的模型，然后假定附件3也有text。**优先考虑对齐版，在训练、验证、测试全过程统一走`text_bert → 同一BERT编码器`的路径，再与audio、vision融合。但必须先核实词表、预训练检查点、特殊token与缺失标记；不能保证任意768维编码器都与附件2的text等价。缺失位置的token不得被作为正常词重新编码而无意恢复可用性。

未对齐版还涉及重新分词、缺失文本的表达方式以及有效长度不明。仅由全零推断真实长度可能混淆尾部填充与尾部缺失。应先查原始生成说明或官方答疑；不能通过在附件2搜索相似文本、匹配原样本、取回缺失特征或标签来“修复”专项测试。

### 2.4 零值与数据质量

附件2两版三模态数值特征全部扫描未发现NaN或Inf；附件3、4已检查的数值输入同样未发现非有限值。但“没有NaN”不表示没有缺失。

以附件2对齐训练集为例：audio有92933个全零时间位置，vision有97117个；text全零位置为0。因存在填充、静默或提取无效等可能，这些数值**不能直接当作人为缺失数量**。尤其text没有全零行，不代表50个位置都有效；应优先使用文本attention mask。

要区分三个概念：填充掩码表示位置本来不属于有效序列；观测掩码表示有效位置是否可用；异常标记表示非有限数或提取失败。应先建立掩码，再用训练集有效、可观测位置拟合标准化参数，否则减均值后全零标记会消失。

## 3. 三问如何理解和展开

### 3.1 问题1：重点是时间对应关系可复核

建议主方案为“冻结预训练特征提取器＋词级强制对齐＋区间池化”，作为一个完整处理体系。文本以附件提供转写为基准；从视频分离音轨，求出词的起止秒数；按真实时间戳提取音频窗口和视频帧特征；再在每个词的时间区间内汇聚对应特征。工具可选BERT类文本编码、开源音频特征工具和面部特征工具，具体版本、许可证及检查点需在实现前核验和锁定。

用第k个词的区间Iₖ=[aₖ,bₖ]作为锚点，某模态m在该区间内的特征可写为：

> **x̄ₖ⁽ᵐ⁾ = Σⱼ wₖⱼ xⱼ⁽ᵐ⁾ / Σⱼ wₖⱼ**

其中wₖⱼ为第j个特征窗口与Iₖ的重叠时长，单位为秒；视觉瞬时帧可按其代表帧区间定义权重。无重叠观测时令输出为零并标记不可用，不执行除零。分子、分母时间单位抵消，输出与原特征同量纲。

需要保存“视频ID／片段ID—词／子词—起止秒—音频窗口—帧号—输出位置”的映射。长样本可以截断或分窗，但必须保留原样本、原始长度、截断位置及覆盖率；不建议不加说明地只取前50个词。问题1自生成特征不必强行复制附件2的74维语音表示，题目没有要求复刻其未知提取流水线。

验收以100条全覆盖、时间边界合法、映射单调、填充可识别、至少1例人工回看对齐为主；不是只比较分类准确率。输出全量汇总建议包含样本ID、视频时长、模态、原始长度、有效长度、特征维度、对齐粒度、异常及截断情况。

### 3.2 问题2：重点是连续片段缺失下的稳定性

数学对象是每种模态随序列位置变化的观测状态，而不是一个全局“有／无模态”开关。对有效位置定义Mₖ⁽ᵐ⁾∈{0,1}，观测输入为Mₖ⁽ᵐ⁾xₖ⁽ᵐ⁾。缺失率为有效位置中不可用位置的比例，分母排除padding。对齐位置未必等长，按位置计算的缺失率与按秒计算的缺失时长必须分别表述。

建议最多两个模型体系：

- 基线：带掩码的时序池化＋固定融合＋双输出头，用来衡量更复杂设计是否真正有效。
- 主模型：带掩码的轻量时序编码、跨模态交互和动态门控，训练时施加连续区间遮挡。门控根据当前样本的剩余证据分配作用，不预设“文本永远最重要”。

分类头给出三类概率pᵢ，回归头输出ŷᵢ∈[−3,3]；一个可实施的监督目标是：

> **L = (1/n)Σᵢ|ŷᵢ−yᵢ| − (λ/n)Σᵢlog pᵢ(cᵢ)**，λ≥0。

n为训练批量样本数，cᵢ为真实类别，λ为验证集选择的任务权重；强度是无量纲分值。训练样本同时包含完整与受遮挡输入，验证时固定遮挡种子便于比较。可在同一模型内增加完整／缺失预测一致性约束，但应由消融证明价值，不在读题阶段预定必然有效。

分类采用三类概率最大者；若采用强度阈值产生类别，必须在验证集选择中性区间并冻结，不能对连续预测只判断“恰好等于0”，否则几乎不预测中性。阈值只改变预测规则，不改变真实标签定义。双头方案另报告分类与强度符号不一致的比例。

实验设计至少覆盖：文本／语音／视觉单模态局部缺失及组合缺失；缺失段位于开头、中间、结尾和随机位置；多种缺失率；同缺失率下一长段与多短段。建议先用0%、10%、30%、50%作为探索网格，并明确这是自定实验参数，不是赛题指定值或附件3真实缺失率。过短样本和四舍五入导致的实际遮挡比例要记录。

评价包括Accuracy、三分类F1、MAE和Pearson相关系数；题目未明确F1平均方式，建议主报Macro-F1并补报Weighted-F1。MAE为平均绝对强度误差；Pearson在真实值或预测值方差为零时未定义，不可硬记为0。消融至少比较无连续遮挡增强、无掩码、固定门控与动态门控。所有“哪种缺失影响最大”的结论都应由实验得出。

### 3.3 问题3：重点是解释可以被反查和验证

建议复用一个完整输入的预测体系，增加归因和遮挡验证，不必再堆叠多个预测模型。解释应分三个层级：

1. 样本级：情感极性、强度、概率或不确定性。
2. 模态级：文本、语音、视觉的作用程度与主要参考模态。
3. 局部级：具体词／短语、语音时间段、视频关键帧。

推荐参考Integrated Gradients（积分梯度）对固定标量输出归因：解释回归时用强度输出，解释分类时固定原预测类别的logit，不在路径上切换目标。每个特征坐标的归因为：

> **IGⱼ = (xⱼ−x′ⱼ)∫₀¹ ∂f(x′+α(x−x′))/∂xⱼ dα**。

x′为基线输入，α为路径积分变量。文本应在连续嵌入或编码特征空间归因，不对整数token编号直接求梯度；固定padding mask，排除特殊token。离散积分步数、基线选择及完整性残差应记录。

把某模态所有有效位置、维度的|IG|相加后，再除以三模态绝对归因之和，得到模态作用份额s⁽ᵐ⁾；最大者为主要参考模态。分母为零时标记“无法区分”，不能任意指定。绝对份额表示作用大小，不表示支持正向；另保留有符号归因解释促进／抑制作用。

使用删除检验复核：遮挡同样数量的重要片段与随机片段，比较固定目标输出变化；辅以不同基线、轻微扰动下的重要性排序稳定性。删除会改变输入分布，因此这类实验衡量模型对证据的依赖，不足以证明现实世界的因果关系。注意力／门控权重可以展示，但不能直接等同于忠实归因。[文献5、6]

**最大落地难点是位置到时间的映射。**附件4有原始视频和文本，但特征文件没有逐词时间戳。第k个特征位置不能直接宣称是视频第k秒，不能无依据地按总时长均分。需要核验原始特征的词／子词组织规则，对提供文本与音轨做强制对齐，再与原特征位置建立可靠映射。未对齐版还需特征提取帧率、截断策略和起始时间。若只能获得近似映射，必须标记近似及误差；在映射核验前，精确秒级定位仍是待解决项。

## 4. 任务合同与边界

| 项目 | 本题的约定 |
|---|---|
| 任务定义 | 三分类＋连续回归；问题1重在提取与对齐，问题2重在局部缺失，问题3重在证据追溯 |
| 数据 | 附件1处理100条原视频；附件2训练3395、验证728、测试727；附件3／4每选定版本30／20条 |
| 结论类型 | 可复核特征、性能与缺失规律、可信归因；本说明不预写性能结果 |
| 模型 | 问题1一个提取对齐体系；问题2一个基线与一个主模型；问题3一个预测体系加归因验证 |
| 数学定义 | 强度范围[−3,3]；三类别固定；观测掩码与padding分离；损失、归因、缺失率按上文定义 |
| 实现 | Python、NumPy、PyTorch、表格读取工具及音视频／文本特征工具；先通过一条样本的训练—专项推理接口检查，再批量训练；最大轮数与早停耐心值在训练前确定，按验证集MAE选主检查点并同时报告分类表现 |
| 验证 | 原始映射抽查、固定划分、缺失对照与消融、四项预测指标、归因删除与稳定性检验；重复种子报告均值和波动 |
| 风险 | 专项接口不一致、padding误认缺失、跨划分来源关联、解释无法回映、训练规模有限、提交体积限制 |

关键假设（放宽会影响方法成立）：①标签编码与强度语义一致，已实查支持；②同一版本经显式适配后训练与专项测试输入语义一致，尚须编码器／token规则核验；③问题3的局部特征能与原素材对应，映射仍待建立。对②③不能写成已满足。

可放宽假设：词区间池化能保留主要情感线索（以更细时间窗复验）；随机连续遮挡能近似真实缺失（改变位置、段数和长度分布复验）；选定归因基线合理（比较多基线和删除结果复验）。以上均是建模假设，不是数据已证明的结论。

所有标准化统计量、重采样策略和可学习参数仅由训练集拟合；验证集用于选择；附件2 test只在方案冻结后评价；附件3、4只用于最终推理。不得引入其他情感数据集训练、微调、调阈值或补统计结果。允许使用的预训练工具与情感任务模型权重应区分说明，不能把外部情感模型继续训练包装成基础特征提取。

## 5. 最容易失分的细节与成果规划

- 题目要求正文呈现100条问题1特征汇总，以及附件3、4全量结果；不能只说“详见附件”。
